# Rover Arm Fall 25

This project contains the source code, configuration, and launch files for the Rover's robotic arm, utilizing the MoveIt 2 and MoveIt Task Constructor (MTC) frameworks, based on the Panda demo resources.

## 🏗️ Setup and Build Instructions

**Prerequisite:** Ensure you have the base ROS 2 distribution (`$ROS_DISTRO`, e.g., Jazzy) sourced in your terminal.

1.  **Clone and Enter the Workspace**
    ```bash
    cd ~
    git clone <repo_link>
    cd rover-arm-f25
    ```

2.  **Import Dependencies**
    Download the necessary MoveIt resource and tutorial packages into the `src/` folder.
    ```bash
    vcs import --input dependencies.repos src
    ```

3.  **Install System Dependencies**
    Fulfill all package dependencies (including core MoveIt libraries like MTC and OMPL).
    ```bash
    sudo apt update && rosdep install -r --from-paths src --ignore-src --rosdistro $ROS_DISTRO -y
    ```

4.  **Colcon Build (Sequential Recommended)**
    Build the workspace. We recommend the sequential executor due to high memory consumption during the first build.
    ```bash
    colcon build --mixin debug --executor sequential
    ```

5.  **Source the Environment**
    ```bash
    source install/setup.bash
    ```

## 💻 VS Code Configuration (Fixing Includes)

If you are getting red squiggles on `#include` lines (C/C++ errors), you need to configure IntelliSense to read the build paths generated by `colcon`.

1.  **Install Extension:** Open the Command Palette (`Ctrl`+`P`) and install the Robotics Developer Environment (RDE) pack:
    ```bash
    ext install Ranch-Hand-Robotics.rde-pack
    ```

2.  **Update C++ Properties:** Open the Command Palette again (`Ctrl`+`Shift`+`P`) and run the command:
    **`ROS2: Update C++ Properties`**
    *(This command uses the `compile_commands.json` file generated by the build to correctly map all MoveIt header paths.)*
